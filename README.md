# Construction Website

A frontend website recreation of Colorlib's **Construction** template, built to practice and strengthen web development skills through real-world layout implementation, styling, and responsive design.

## Overview

This project recreates the visual design and layout of a construction company website using the original template as a reference. It focuses on matching the page structure, typography, colors, imagery, navigation, and overall user experience as closely as possible.

The project is intended for educational purposes and demonstrates practical frontend development skills.

- **Pixel-focused UI recreation** — aims to reproduce the reference design as accurately as possible.

- **Responsive layout** — designed to adapt to different screen sizes, depending on the implemented media queries.
- **Reusable styling** — organized CSS for maintaining consistent spacing, colors, and typography.
- **Cross-device testing** — intended to provide a consistent experience across desktop, tablet, and mobile devices.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- A modern web browser.
- A code editor such as Visual Studio Code.
- Git, if you want to clone the repository.

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd construction-replica
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
